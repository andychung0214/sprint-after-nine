## 手動回歸腳本

1. 清空本遊戲進度，選 Junior／前端；在協作白板選較仔細的作法。
2. 09:30 參加站會，回座位開發，再到測試站驗證，最後處理審查。
3. 故意選跨會議時段的任務，確認取消不改變指標，略過只扣一次信任。
4. 事件出現時重載，續玩後仍須回覆；前往茶水間休息或午休。
5. 暫停後按方向鍵、切換分頁再返回，確認沒有背景移動。
6. 提早下班或走到 18:00，檢查結算、已完成清單與決策紀錄。
7. 換 Senior／後端及 Lead／全端，確認不同任務文案與相同可操作性。
8. 窄螢幕以觸控完成同一流程，檢查站點列、對話框與焦點不遮住必要操作。
