# 九點以後：美術規範

## 方向

採用「低多邊形辦公室 × 紙本工作日誌」。曾評估像素辦公室、黑白漫畫與終端機風格；本案使用可探索的桌上模型，搭配右側便條式工作日誌。識別元素為略微歪斜的 9: 打卡標記及結算印章。

## 色票與字體

| 用途 | 色碼 |
|---|---|
| 紙張底色 | #F2EDE3 |
| 墨色文字 | #25332D |
| 森林綠主色 | #385747 |
| 木質家具 | #B98C62 |
| 警示與印章 | #AD5142 |
| 卡紙 | #FFFCF5 |

內文使用 Noto Sans TC（若本機有安裝）、Microsoft JhengHei、系統無襯線字體；不下載外部字型。標題使用同字體粗體、緊字距與換行；時間／站點編號使用 Consolas 等寬字體。內文 13–15px，主標 56–64px，重要操作最小高度 44px。

## 版面與元件

桌機使用主場景加 365px 日誌，768px 級距縮小日誌，760px 以下改為上下排列。九個站點始終可用按鈕到達；手機以水平捲動列保留 72px 觸控寬度。任務卡清楚標示時間與每個指標效果；紅點與文字同時提示下一步。狀態列使用數字與進度條，不只用顏色。

## 模型與動畫

模型為原創 three.js 幾何家具、隔間、植物與人物。可縮放的等角鏡頭、柔和日光、偏綠灰地板、木色桌面。角色移動與站點提示有目的，無不必要的鏡頭晃動。像素比例上限 1.25，長時間更新偏慢時逐步降至 0.65；尊重 prefers-reduced-motion。音效預設關閉。

## 禁止事項

不使用滿版漸層、霓虹光暈、玻璃卡片堆疊、無意義數字標籤；不複製參考站圖片與角色。不使用真實公司識別或員工資料。角色語氣不羞辱職級。Blender 為可選製作流程，首版無未驗證的 .blend 或 Unreal 產物。

## 驗證

對比與實際畫面檢查紀錄於 TEST-PLAN.md；設計規範不等於已通過的驗證證據。

## 2026-10-31 擴建

地板由 117 增至 308 平方場景單位。接待木櫃、雙螢幕與可調扶手椅、玻璃隔間、投影設備、機櫃格柵、UPS、咖啡機、冰箱與沙發使用一致尺度。家具採手工幾何造型，非寫實掃描。

角色使用關節步態及指數平滑轉身；工作手勢、咖啡蒸氣、機櫃燈號屬呈現，不耗遊戲時間。減少動態效果停用裝飾動畫與鏡頭插值。暫停／背景分頁停止場景動畫。靜態家具按材質合併繪製、陰影快取、Lambert 材質降低成本，移動人物不寫入凍結陰影，以腳底圓環表示位置。
